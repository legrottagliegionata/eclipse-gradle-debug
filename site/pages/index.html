Gradle Task Debugger for Eclipse

Version ${qualifiedVersion}

Debug any Gradle task from Eclipse the way IntelliJ IDEA does it: right-click a task in the Gradle Tasks view and choose Debug Gradle Tasks. The debugger is attached to every JVM the build forks (run, bootRun, test, …), with hot code replace of the classes Gradle compiles.

No Remote Java Application, no Launch Group, no fixed debug port.

Install

From the Eclipse Marketplace: drag this button to a running Eclipse, or search for Gradle Task Debugger in Help → Eclipse Marketplace…

Or use this page, which is an Eclipse update site. Add its address in Eclipse:

https://legrottagliegionata.github.io/eclipse-gradle-debug/
  1. Help → Install New Software… → Add… and paste the address.
  2. Select Gradle Task Debugger for Eclipse, then Next and Finish.
  3. Restart Eclipse.

The update site is signed with PGP (key F674BC99350CB3A0). Requires Eclipse 2024-06 or later with Buildship 3.1, and Java 17.
